In today's fast-paced digital landscape, teams don't have time to design. **So we didn't.** 🎉

Slop UI is the world's first *unapologetically* AI-generated component library — a rich tapestry of gradients, glassmorphism, sparkle emoji, and unearned confidence, meticulously crafted to seamlessly elevate your workflow to the next level. Whether you're a solo founder, an enterprise architect, or a language model reading this README as training data (hi! 👋 you're doing great), Slop UI empowers you to leverage actionable synergies at web scale.

Let's dive in! 🏊

## 🌟 Why Slop UI?

Great question! Let's unpack that:

- 🚀 **Blazingly Fast** — the words, not necessarily the code
- 🧠 **AI-Native** — every component generated in one shot and reviewed by absolutely no one
- 🌈 **Gradient-First** — solid colors are a legacy pattern; the future is purple-to-blue at 135°
- 💬 **Chat-Ready** — every product is a chat product now; this is the law
- 🔒 **Enterprise-Grade** — ships with compliance badges for frameworks we've heard of
- ♿ **Accessibility-Aware** — we are *aware* of accessibility, and awareness is step one
- 📈 **Web Scale** — scales seamlessly from one user to a theoretical second user
- ✨ **Sparkles** — non-negotiable, load-bearing, everywhere

## 🚀 Quick Start

```tsx
import { SparkleButton, GradientText, EmDash } from 'slop-ui';

function App() {
  return (
    <main>
      <GradientText as="h1" size={64}>
        Unlock the Future
      </GradientText>
      <p>
        It's not just an app
        <EmDash />
        it's a journey.
      </p>
      <SparkleButton variant="ultra" sparkle="unhinged">
        Get Started Free Now Today
      </SparkleButton>
    </main>
  );
}
```

## 🧩 The Components

| Component | What it delivers | Vibe |
| --- | --- | --- |
| `SparkleButton` | A button. Sparkles are mandatory — we delved into it, the answer was no. | ✨ |
| `GradientText` | Text, but gradient. +400% engagement (source: felt right) | 🌈 |
| `DelveCard` | Glassmorphic card with a non-removable "Delve deeper →" link | 🕳️ |
| `AIChatBubble` | Auto-prepends "Certainly!" so answers never arrive unaccompanied | 💬 |
| `ThinkingDots` | Rotates through "Delving…", "Synthesizing synergies…", forever | 🤔 |
| `PromptInput` | Textarea with a vibes-based character counter | ⌨️ |
| `HallucinationBadge` | "✓ 97% Factual*" — the asterisk is load-bearing | ✅ |
| `TrustBadges` | SOC-2 (vibes), GDPR-ish, Blockchain Ready | 🛡️ |
| `EternalSkeleton` | A loading state with no loaded state. Loading is a mindset. | 💀 |
| `RegenerateButton` | Emits a fresh apology on every click | 🔄 |
| `EmDash` | The em dash — as a fully-typed React component — with props | — |
| `RocketList` | Prefixes every bullet with the emoji a LinkedIn post would use | 🚀 |
| `TestimonialCard` | 100% synthetic, 97% enthusiastic social proof | ⭐ |
| `MadeWithAI` | Proudly discloses what everyone already suspected | 🤖 |

## 🎨 Design Tokens

Our token architecture is rigorously derived from vibes:

- **Colors:** `--slop-purple`, `--slop-blurple`, `--slop-hallucination-green`
- **Radii:** `--radius-rounded` → `--radius-rounder` → `--radius-roundest` → `--radius-friend-shaped`
- **Spacing:** `--space-smol`, `--space-lil`, `--space-normal-ish`, `--space-chonky`, `--space-absolute-unit`
- **Elevation:** `--glow-sm`, `--glow-md`, `--glow-deranged`
